# 界面设计系统

界面遵循「活泼明快」风格：橙色主色、圆润字体、圆角卡片、统一矢量图标。本文件是视觉与交互的唯一规范；设计令牌以 `src/style.css` 的 `:root` 变量为代码真相源，两者冲突时以本文件为准。

## 设计基调

- 活泼明快：高饱和橙色为主、暖色卡片、明显但不过度的按压反馈，营造轻松、有动力的学习氛围。
- 圆润亲切：大圆角（14–24px）、圆润字体（拉丁与数字用 Nunito）、柔和双层阴影。
- 不幼稚：控制留白与层级，不使用儿童式夸张造型；每屏一个主 CTA。

## 颜色（语义令牌）

| `--on-primary`                                 | `#2B1A0A`                         | 橙色上的文字（保证对比度） |

| `--ink`                                        | `#2B1A0A`                         | 主文字                     |
| `--ink-soft`                                   | `#5C4633`                         | 次要文字                   |
| `--muted`                                      | `#6B4F35`                         | 辅助文字（≥4.5:1）         |

- 正确/错误必须同时有图标或文字说明，不得单靠颜色传达。
- 深色模式尚未实现；令牌已预留，后续补齐时需单独验证对比度，不能直接反转现有值。

## 字体与排版

- 字体栈：`"Nunito", "PingFang SC", "Microsoft YaHei", "HarmonyOS Sans SC", "Hiragino Sans GB", "Noto Sans SC", sans-serif`。Nunito 由 `index.html` 以 `display=swap` 加载。
- Nunito 只覆盖拉丁字母与数字；中文/日文按系统字体回退，跨平台无法保证圆润属预期，不得为此引入体积过大的 CJK 字体包。
- 字号下限 12px，正文 15–16px；不再使用 9–11px 的正文或标签。
- 层级：h1 28–32px/800、h2 20–22px/700、h3 17–18px/700、正文 15px/500、辅助 13px。
- 行高 1.6–1.75；数字用 `font-variant-numeric: tabular-nums` 对齐。

## 形状、阴影与动效

- 圆角：卡片 18px、按钮 14px、胶囊 999px、小元素 10px。
- 阴影：柔和双层阴影；主按钮用厚底边 + 按压 `translateY` 的 claymorphism 简化版。
- 动效：过渡 150–250ms、ease-out；尊重 `prefers-reduced-motion`；状态切换显式设置终态，不依赖动画结束事件。

## 图标

- 统一使用 `@phosphor-icons/react`，线性风格（`weight="regular"`），默认 20px，随文字基线对齐。
- 导航图标：首页 `House`、路线 `MapTrifold`、五十音「あ」、单词 `Stack`、对话 `ChatCircle`、设置 `Gear`。
- 五十音导航保留日文字符「あ」（非 emoji，语义最贴切），其余一律矢量图标。
- 禁用 emoji 作为结构性图标；emoji 仅允许出现在用户内容与装饰性插画中，且不得承担导航或状态语义。

## 交互与无障碍

- 触控目标 ≥44px；按压反馈在 100ms 内；禁用态用 0.5 透明度 + 非交互语义区分。
- 键盘焦点环可见（2px 主色、offset 2px）；表单有可见 label；错误就近说明并用 `aria-describedby` / `role="alert"` 关联。
- 每屏一个主 CTA，次要动作弱化；破坏性动作与常规操作分离。

## 落地位置

- 令牌与基础布局：`src/style.css`；卡片与组件：`src/cards.css`。
- 新增组件复用现有类名与令牌，不在组件内写死颜色、字号或圆角。
