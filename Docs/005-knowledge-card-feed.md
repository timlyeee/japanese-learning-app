# 知识卡片信息流

> 状态：已完成

## 背景

首页将从单纯的学习概览逐步转向知识内容信息流。知识卡片可以代表短文、文章、视频或混合内容；测试、复习卡和用户数据不再与卡片正文混为同一结构。

本阶段先将现有五十音内容接入新的知识卡片模型，并在首页提供逐批加载的信息流。点击内置五十音卡片后，进入对应的既有学习内容。

## 数据模型

- `KnowledgeCard`：可发布、可收藏的知识内容身份，保存作者、发布状态和当前版本。
- `CardRevision`：一次不可变的内容快照，保存标题、摘要、内容块、随卡测试引用和复习项引用。
- `ContentBlock`：可组合的正文块。本阶段实现富文本、假名网格和提示块，并为图片、视频等类型保留类型定义。
- `StudyDeck`：复习项的集合。平假名和片假名分别作为内置卡组，引用对应知识卡片与复习项。
- 现有 `Card` 暂时保留，继续服务课程和 AI 卡片功能；后续迁移时应改名为 `StudyItem`，避免与知识卡片混淆。

## 首页信息流

- 内置平假名、片假名分组分别生成知识卡片，使用稳定的卡片 ID、版本 ID、测试 ID和复习项 ID。
- 首页首批只渲染少量卡片，后续通过游标分页追加，避免一次渲染全部内容。
- 使用 `IntersectionObserver` 在列表尾部接近视口时自动加载下一批。
- 始终保留“加载更多”按钮，作为键盘操作和不支持观察器环境的兜底。
- 列表使用稳定 ID 作为 React key；加载状态通过 `aria-busy` 和状态文本暴露。
- 点击卡片进入对应平假名或片假名分组的现有学习页面。

## 非目标

- 本阶段不实现远端推荐接口、社交作者系统、收藏同步、私人标注、测试反馈和作者修订界面。
- 本阶段不实现从首页卡片到全屏详情的共享元素动效；卡片先复用已有五十音学习详情。
- 分页数据目前来自内置静态数据，但游标接口可直接替换为服务端分页结果。
